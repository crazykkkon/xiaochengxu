# 《最后的绿洲》游戏设计方案 v0.1

> 类型：环形布局的生存城建 + 社会抉择
> 平台：微信小游戏 / 抖音小游戏（竖屏）
> 变现：激励视频广告（无内购，不需要版号）

---

## 一、一句话概括

大旱百年，你带着最后 80 名幸存者找到一口古井，在井上建起**「心泉塔」**。全城围着它一圈圈向外扩建。你要在 **30 天**内撑过不断升级的热浪和沙暴，迎接最终的灾难：**「黑风」**。

---

## 二、核心设计：一切围着「心泉塔」转

### 2.1 心泉塔（城市的心脏）
- 位于地图正中央，负责**抽水、喷洒水雾降温**。
- 塔有 **4 档功率**：关闭 / 低 / 标准 / 超载。
  - 功率越高：降温范围越大、温度越低，但**消耗燃料越多、井水下降越快**。
  - 超载可以救命，但持续太久会**损坏**（需要停机维修，期间全城无水）。
- 塔可以升级 3 次：扩大覆盖圈、降低能耗、解锁"夜间储水"。

### 2.2 环形城市布局
地图是以塔为圆心的**同心圆格子**（共 5 圈），每一圈按扇区划分地块：

| 圈层 | 体感温度 | 适合建造 |
|---|---|---|
| 第 1 圈 | 最凉爽 | 住所、医馆 |
| 第 2 圈 | 凉爽 | 厨房、工坊、配水站 |
| 第 3 圈 | 炎热 | 农场、仓库 |
| 第 4 圈 | 酷热 | 采集站、太阳能板 |
| 第 5 圈 | 极热（塔覆盖不到） | 矿场、瞭望塔，需要靠「遮阳棚」「配水站」续命 |

**设计意图**：越靠里越安全，但内圈地块很少；越往外资源越多，代价是越热。玩家会一直纠结"把什么放在里面"。

### 2.3 昼夜温差（和同类游戏不同的地方）
- **白天**：酷热，户外工作效率下降，有人中暑。
- **夜晚**：骤冷，需要燃料取暖，但这是**最佳的储水、采集时段**。
- 玩家可以通过法令改作息，比如"夜班制"：白天休息、夜里干活。

## 三、资源系统

| 资源 | 来源 | 用途 |
|---|---|---|
| 💧 **水** | 心泉塔、冷凝收集器、驼队带回 | 饮用、农业、降温（最核心的生死线） |
| 🌾 **粮食** | 沙地农场（耗水）、猎人小屋（仙人掌、沙蜥） | 吃饭，生病率跟它挂钩 |
| 🔥 **燃料** | 枯木、油页岩矿 | 心泉塔运转、夜间取暖 |
| ⚙️ **零件** | 废墟拆解、工坊 | 建造、升级 |
| 💎 **水晶核心** | 只能靠探索获得 | 高级建筑、塔的升级 |

**井水深度**：一个全局数值，会随抽水量慢慢下降。降到警戒线以后抽水效率减半，必须研发「深钻」或者找到新水脉。这是长期压力来源。

## 四、人口与民心

### 4.1 人口构成
- **劳工**：基础采集、建造
- **工匠**：工坊、医馆、研究所需要
- **孩童**：不能工作（除非颁布「童工法令」），长大后会成为劳工

### 4.2 两个民心指标
- **🌅 盼望值**：大家还相信能活下去吗？降到 0 = 失去信念，游戏失败。
- **😠 躁动值**：大家对你有多不满？满了 = 被流放，游戏失败。

每个决策都会同时影响这两个值。玩家要在"活下去"和"做个人"之间找平衡。

### 4.3 健康状态
正常 → 中暑 / 脱水 → 重病 → 死亡（或致残）。生病的人不能工作，医馆床位有限。

## 五、法令系统：《绿洲公约》

每隔一段时间（冷却 1 天）可以颁布一条法令。法令**不可撤销**，分两大类：

### 5.1 生存法令（示例）
| 法令 | 效果 | 代价 |
|---|---|---|
| 定量配水 | 用水 -30% | 盼望 -，脱水率 + |
| 夜班制 | 夜间效率 +，中暑率 - | 躁动 +（作息颠倒） |
| 童工法令 | 孩童可做轻活 | 盼望 -- |
| 沙葬 | 遗体可回收水分 | 躁动 +++，盼望 - |
| 截肢求生 | 重病者存活率 + | 产生残障人口 |
| 难民接纳 | 人口 + | 资源压力 + |

### 5.2 中期路线选择（第 10 天左右，二选一）
- **🐪 商盟之路**：建立贸易站和集市，靠驼队交易换资源；后期可以颁布"债务契约""水权买卖"等高效但冷酷的法令。
- **☀️ 沙神之路**：建立神殿，用信仰稳定人心；后期可以颁布"献祭仪式""守夜人"等法令，民心稳定但越来越偏执。

两条路线各有 6 到 8 条进阶法令，最终法令会带来**强大增益和沉重代价**，也决定玩家看到的结局。

---

## 六、科技树（研究所）

三条分支，研究要消耗时间和零件：
- **水利**：冷凝收集器 → 深钻 → 地下蓄水池 → 心泉塔 Lv2/3
- **生存**：遮阳棚 → 医馆扩建 → 耐旱作物 → 蒸馏净水
- **探索**：瞭望塔 → 驼队 → 沙地履带车 → 远征营地

---

## 七、探索：驼队远征

- 地图外有一张**沙漠大地图**，派驼队（3 到 5 人）去探索地点。
- 地点类型：废弃城镇（零件）、干涸湖床（水晶）、幸存者营地（人口）、古代水渠（新水脉）。
- 探索途中会触发**文字事件**，比如：遇到垂死的旅人，要不要分水给他？
- 驼队可能**一去不回**，给玩家带来不安和期待感。

---

## 八、剧情流程（主线 30 天）

| 阶段 | 天数 | 主要事件 |
|---|---|---|
| 扎根 | 1–5 | 教学：建塔、建住所、基础资源 |
| 挣扎 | 6–12 | 第一次沙暴，路线抉择，驼队解锁 |
| 动荡 | 13–20 | 井水告急，难民潮，派系冲突事件 |
| 绝望 | 21–27 | 连续热浪，人心崩溃边缘，最后的储备 |
| 黑风 | 28–30 | 持续 3 天的终极沙暴，所有人躲进内圈，考验前期准备 |

**结局**：撑过黑风后，根据路线和法令的选择，出现不同的结局文字，比如"你建立了一座城，但它还记得自己为何而建吗？"，用来引发玩家分享和讨论。

**后续模式**（上线后再加）：无尽模式、挑战剧本（如"商队遗孤""移动城市"）。

## 九、广告设计（激励视频）

**原则**：广告只在"玩家自己想要"的时候出现，绝不强制；每局限次数，避免破坏平衡。

| 触发时机 | 广告奖励 | 单局次数 |
|---|---|---|
| 💀 **失败时** | 「最后的希望」：回到前一天开头，并获得一批补给 | 1 次 |
| 🌪️ 沙暴/热浪预警时 | 「商队来援」：立即获得水 + 燃料 | 2 次 |
| 💧 井水告急时 | 「发现水脉」：井水深度恢复一截 | 1 次 |
| 🏗️ 建造/研究中 | 「全员加班」：立即完成当前建造或研究 | 每天 1 次 |
| 🐪 驼队遇险时 | 「沙漠向导」：驼队安全返回 | 不限（但有冷却） |
| 📦 每日登录 | 双倍领取每日补给箱 | 1 次 |
| 🏆 通关结算 | 解锁"历史档案"（全城编年史、死者名册），可以分享 | 1 次 |

**收益关键**：难度曲线要让玩家在**第 6 天、第 15 天、第 22 天、第 28 天**附近出现"差一点就能活下来"的危机，这几个节点就是自然的广告转化点。

**分享裂变**：失败或通关时生成"城市墓志铭"卡片（存活人数、颁布过的残酷法令、一句结局语），可以分享到群里或朋友圈、抖音。

## 十、小游戏平台适配

- **竖屏操作**：地图双指缩放、单指拖动；底部是建造栏，顶部是资源栏，右侧是法令和事件入口。
- **单局节奏**：1 天约 2 到 3 分钟（可以 1x / 2x / 3x 倍速），完整通关约 1.5 小时，可以分很多次玩。
- **自动存档**：每天结束时自动存档，切出去再回来不会丢进度（本地存储 + 云存档）。
- **包体**：首包控制在 4MB 以内，美术和音频走分包或 CDN 远程加载。
- **防沉迷/合规**：准备软件著作权、隐私协议、适龄提示；暴力、死亡相关描述保持克制（文字为主，不出现血腥画面）。

---

## 十一、技术方案

- **引擎**：Cocos Creator 3.x + TypeScript，一套代码导出微信和抖音两个平台。
- **架构**：
  - `core/`：纯逻辑模拟层（资源、人口、温度、民心计算），不依赖引擎，方便写单元测试和数值调优
  - `config/`：建筑、法令、事件、科技全部用 JSON 配置，策划改数值不用改代码
  - `view/`：渲染与 UI
  - `platform/`：广告、分享、存档的平台适配层（微信、抖音、浏览器调试三套实现）
- **数值调优**：做一个"自动模拟器"，用脚本跑几千局，看不同策略下各天的存活率，用来校准难度曲线和广告节点。

## 十三、和《冰汽时代》的区分（规避侵权）

借鉴的只是**玩法类型**（围绕核心建筑的环形布局、法令抉择、生存压力），这类机制不受版权保护。具体到内容：
- 题材换成沙漠干旱，核心资源换成水，加入了**昼夜温差**机制
- 名称全部原创（心泉塔、绿洲公约、盼望值、躁动值、黑风……）
- 路线、法令、事件、剧情、美术、UI 都自己设计，不照搬原作的具体条目和界面
- 加入原创系统：井水深度、驼队远征、广告救援
