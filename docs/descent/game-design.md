## 一、一句话概括

你失足掉进一口很深的井，只能一层层往下走。每一层是一张格子地图，怪物的数值全部公开，打一只怪要掉多少血可以提前算出来。第一次下井会被井底的东西打断一条胳膊，断口长出一个**转轮**——之后每一局，你都要往这条断臂上刻武器、拉杆转武器，一路走到第 20 层的井底。

**卖点**：每一层都算得清；唯一的运气在断臂转轮和大转盘上，而且花多少钱、要不要赌，都由你决定。

---

## 二、设计目标

1. **保留数值解谜的乐趣**：楼层里没有运气成分，赢靠算，输了也是自己算错了。
2. **肉鸽的新鲜感**：每局的地图、路线、刻上的武器都不一样，可以反复玩。
3. **赌，但赌的是判断**：随机只发生在断臂转轮、大转盘和"走哪个出口"上；转不转、花多少、走哪边，自己算。
4. **单层 1～2 分钟**，随时可以退出、继续。一局 20 层先按熟悉规则后 30～40 分钟测试（交接稿建议，讨论项）。

## 三、一局的结构

- **已确认**：公开 Demo 只有一位英雄，一局 **20 层**，在同一局里从第 1 层走到第 20 层，击败井底 Boss，看到通关结算。
- **沿用原案**：首位英雄是掘井人；整层一屏可见；战斗结果确定；下楼后不能回上层；中途可以退出续玩；死亡后重新开局。
- **制作人定**：第一局是**新手教程**（第 1～5 层，第 5 层被井底之眼打死，见第六章）；之后每一局从第 1 层开始，带着断臂转轮。

| 层 | 内容 |
|---|---|
| 1、2 | 只有一条路，教学难度的普通层。第 1 层一定有一只带印记的怪，帮玩家刻上第一把武器 |
| 3 | 只有一个候选（随机一张普通层）；开头第一张诏令 |
| 4～9 | 每层两个候选（地图上两个出口各通一个）；第 8 层开头第二张诏令；**第 9 层出口交井租 120 金** |
| 10 | 中段精英（石鳞守卫 + 骸骨祭司），固定 |
| 11 | 只有一个候选 |
| 12～18 | 每层两个候选；第 13 层开头第三张诏令；**第 17 层出口交井租 250 金** |
| 19 | 守门人 + 两只骸骨祭司，固定 |
| 20 | 井底之眼，固定 |

- **制作人定**：第 1、2、10、19、20 层只有一个出口。所以第 3、11 层只有一个候选；第 9、18 层的下一层固定，也只有一个出口。
- 精英、Boss 的层位，井租的层位和金额，诏令的层位都是讨论项（交接稿建议过守门人第 19 层、井底之眼第 20 层、第 10 层中段精英、两次井租）。

## 四、单层规则（数值解谜）

### 4.1 地图
- **制作人定**：每层地图 **16×11 格**，整层一屏看全，不用滚动。
- 格子：墙、空地、怪物、道具、门、入口、出口，以及设施（补给摊、大转盘、当铺、骨坛，站在旁边用）。
- 地图里有岔路、环道和侧室：几条路都能到出口，各有不同的守卫和代价；奖励放在侧室里，门口有怪守着。

### 4.2 角色属性

| 属性 | 初始值（掘井人） | 说明 |
|---|---|---|
| 生命 | 200 | 归零即死亡 |
| 攻击 | 10 | 每次攻击造成"攻击 − 对方防御"点伤害 |
| 防御 | 10 | 每次受击减免这么多伤害 |
| 骨钥 | 0 | 开骨门 |
| 金币 | 0 | 转断臂转轮、大转盘、当铺、补给摊、交井租 |

掘井人原来的特长"宝石效果 +1"去掉了（制作人 2026-11-24：小宝石就是 +1、大宝石就是 +3）；要不要给他换一个特长是讨论项。

### 4.3 战斗（固定，没有随机）
- 主角先出手，双方轮流攻击，直到一方生命归零。主角每次造成 max(攻击 − 怪物防御, 0)，怪物每次造成 max(怪物攻击 − 主角防御, 0)。
- **不直接告诉玩家要掉多少血**（制作人 2026-11-24 定）：怪物头上不挂掉血牌；鼠标指着怪物或者走到它旁边，地图下方显示它的生命、攻、防、特性和掉落的金币，**不给预计战损**，玩家自己算。
- **打不动、打不过的怪也照样能打**（制作人定）：攻击不高于它的防御时，你每下打出 0，它一下下把你耗死；打不过就死，这一局结束。出手前**不再提醒"打下去你会死"**（那句提醒等于把答案告诉了玩家）。
- 只有一种情况打不起来：你打不动它、它也伤不到你（双方都是 0，又没有反伤），这时提示"打不动X，它也伤不到你"，人不动。
- 打赢后主角站到怪物原来的格子上（Codex 定的表现，制作人确认）。
- 例子：攻 10 / 防 10 打井苔（生命 30 / 攻 15 / 防 2），每次打 8 点、4 次打死，井苔还手 3 次、每次 5 点，**掉 15 血**。

### 4.3.1 战斗过程和打击反馈（制作人 2026-11-24 提出；具体表现是默认做法）
结果还是开打前就定好的，但不再一下子结算完，而是把每一下演出来。
- **每场都弹战斗窗口**（制作人 2026-11-24 定：魔塔式，"每场都弹"）：画面中间弹出一个窗口，矿工和怪物站在同一块场地上（左矿工、右怪物，**中间不写 VS**），下面各一条大血条和"现有 / 最大"生命，标题写着第几回合；两边一来一回地打，血条和顶栏的生命一下下往下掉。打完窗口关上，主角站到怪的格子上。
- **真的打到对方身上**（制作人定：手要打上去、怪物的口水要喷出来）：矿工每一下冲到怪跟前，用手上的武器打在怪身上再退回来——空手是一拳，刀类劈砍，鱼叉直刺（站得远一点），锤类砸下，钩类钩一下。怪按种类出手（具体分配是默认做法）：
  - 近身：盲鳗 / 刺鳗 / 井鼠扑上来咬（牙印），甲虫和精英冲撞，蟹类钳夹（爪痕）；
  - 远程：井苔 / 棘苔 / 盐蚀蛞蝓喷口水（抛物线飞过去溅开），骨蛙 / 铠蛙吐舌头，蝠类放声波，溺魂 / 怨魂放鬼火，骸骨祭司甩骨刺，井底之眼放光束。
  - 打中的那一刻才掉血、弹数字；挨打的一方闪一下、往后一退。倒下的矿工躺在地上。
- 打不过的仗也演完：在矿工倒下的那一下停，窗口里写"你倒下了"。打不动的仗每下弹一个灰色的"0"。
- 长仗（比如血很厚、被一点点耗死）：先演开头 8 下，中间快进一下（弹"…… 又打了 N 回合"，血条一口气滑下去），再演最后 6 下。
- **出手有武器动作**：挥砍（弧光）、突刺（直线）、锤击（冲击圈），颜色按武器不同；主角扑向怪，怪挨打时闪白、往后一退；怪出手时扑向主角，主角闪红。
- **伤害数字弹出**：每一下的伤害从被打的一方头上弹出来（先放大再缩回、往上飘），带深色描边；打死那一下数字更大。顶栏的生命跟着一下一下往下掉。
- **特殊效果用不同颜色**：先手（黄）、连击（橙红）、破甲（橙）、克制吸血 ×2（青）、腐蚀（黄绿）、反伤（紫）、主角吸血（绿）、怪吸血（暗红）。
- **击杀**：打死那一下画面顿住一瞬间、大震，怪发白、缩小、碎成碎片四散，碎裂声。
- **击杀后的夸奖**（只挑最值得夸的一句）：
  - **算准了！**：这一层里它曾经"打不动 / 打不死 / 会死"，你备好战再回来把它打死了——也就是"算出刚好能打死它"的那一下。
  - **千钧一发！**：打完只剩不到 1/10 的血（或 10 血以下）。
  - **无伤！**：它本来伤得到你，你一滴血没掉就打死了。
  - **连杀 ×N**：4 秒之内接着打死下一只，音调一次比一次高。
- 每一下约 0.34 秒（冲过去、打中、退回来），一场最长约 3 秒（下数多就把每一下压短）；打的时候点一下或按任意键跳过剩下的；设置里可以选"战斗动画：正常 / 快 / 跳过"。
- 规则那边只加了一份"每一下打了多少"的记录（原型 `simulateCombat` 的 log，Lua 版同步，标准算例逐下对账），结果不变。

### 4.4 道具

| 道具 | 效果（浅层 / 深层 / 井底） |
|---|---|
| 小血瓶 | +50 / +50 / +60 生命 |
| 大血瓶 | +150 / +120 / +150 生命 |
| 小赤晶 / 小青晶 | +1 攻击 / 防御 |
| 大赤晶 / 大青晶 | +3 攻击 / 防御 |
| 骨钥 | +1 |
| 金币袋 | +25 / +30 / +40 金币 |

- **宝石分大小**（制作人 2026-11-24 定）：第 1～6 层只有小宝石；第 7 层起会出现大宝石，但概率很小，一层最多一颗；后面的层大小宝石都有。
  - 默认做法（概率是讨论项）：第 7～10 层每层 25% 有一颗大宝石；第 11 层起每颗宝石是大的概率 30%，每往下一层 +4%，最多 70%。按种子定好，求解器照样能算。
  - 新手教程里的宝石都是大宝石（+3），教程的数值不变。
- 打败怪物也掉金币，越强掉得越多（见 4.7）。
- 走过的血瓶就喝掉；**没喝的血瓶在出口折成金币**（每瓶 5 金），身上的骨钥可以在出口卖掉（每把 15 金）。

### 4.5 门
- **骨门**：用掉 1 把骨钥打开。
- **血门**：不用钥匙，直接扣固定生命（第 1、2 层 40、60，之后浅层 80、深层 100、井底 120；教学关卡另算）。

### 4.6 过关
- **走到出口就进入下一层，不用清怪。** 解谜的重点是"哪些值得打、哪些可以绕开"。
- **精英层**：精英活着时出口被封住，必须打败它。
- **没有撤回、没有重开本层**：走过、打过、开过的门都不能退回。走进死局（活着到不了出口）就只能新开一局。
- 走上出口前问一次（"再想想"留在本层）；**只能往下走，不能回到上一层**。
- 奖励都放在怪物身后，开局不打怪就能白拿的宝石和血瓶不放。

**数值体检和难度目标**（制作人 2026-11-24 定：**第一次玩大约 10% 通关；输了去碎片商店买强化，买满以后大约一半能通关**；宝石分大小）
- 量法：`tools/balance.ts`。模拟一个"会算"的玩家：每层用求解器算这一层的最优打法（生命和攻防一起权衡，一点攻 / 防当 10 血），精英奖励选攻击；**不算武器、大转盘、当铺、骨坛、诏令**。60 个种子 × 两种选法 = 120 条路线。

| | 不加强化 | 碎片强化买满 |
|---|---|---|
| 通关率 | 7% | 53% |
| 大多倒在 | 第 9～12 层 | 第 19、20 层（守门人、井底之眼） |

  真人会从断臂转轮拿到武器（更容易），但每层不一定算得出最优打法（更难），两头大致抵消，所以按这个玩家定目标。每层都算最优打法的"完美玩家"不加强化大约一半能通关。

## 五、断臂转轮和这一局的成长

### 5.1 制作人定下的方向
1. **去掉井的契约**（押血、不喝药、毁约全部去掉）。
2. **去掉武器格**：地图里拿不到武器，武器只能从断臂转轮转出来。
3. **刻图案**：打败精英可以选刻一把武器（精英奖励三选一里的一项）；带印记的怪被打败后也能刻；当铺可以花钱刻；大转盘也可能转出新图案。图案可以擦掉。刻得越多，转到它的机会越大，相当于强化这把武器。
4. **每局清空**：断臂一直在，图案每局从空开始。
5. **想换武器时自己转**（花金币或生命）；**转到的机会小才有难度**。

### 5.2 转轮的结构（制作人定）
- **三个轮子并排，每个轮子一圈 5 格**。画面上每个轮子露出上中下 3 格，中间那格是转到的；按住一个轮子上下拨动能看整圈，松手弹回。
- **刻图案只刻在一个轮子的一格上**，玩家自己点刻在哪一格（只能刻在空格上，见下面的"刻图案的场景"）。
- **只看中间一行**：三个中间格是同一把武器 → 换成它；三个都是空格 → 空手；其他 → 手上的武器不变。
- 概率 = 三个轮子上这把武器各占几格 ÷ 5，三个相乘：各刻 1 格 0.8%，各 2 格 6.4%，各 3 格 21.6%；有一个轮子上没有就转不出来。转轮下面一直显示"转到各武器的几率"。
- **锁轴更贵（制作人定）**：锁住一两个轮子只重转其余的；锁一个付 2 倍、锁两个付 3 倍（倍数是讨论项）；锁轴也算转了一次。
- **赖子（制作人加）**：能顶替任何武器，拿到的机会很小。中间一行除赖子以外都是同一把武器就算连成（"刀·赖·刀""赖·赖·锤"都算）。

默认做法（讨论项）：
- 转一次：每层第一次 10 金，之后每次 ×1.5，**换层重新算**（制作人喜欢这个机制；上一层转过的话，进新的一层时底部会提一句"价格回到 10 金"）；也可以用生命付（×1.5）。
- **刻上不等于拿到**（制作人 2026-11-24：刻上的图案不能默认落在中间一行，不然三个轮子刻一样的，不用转就拿到武器了）：刻图案时轮子不动，默认刻在中间那格的下一格（只剩中间那格空着才刻在中间），手上的武器不变，要拉杆转到才换成它。
- **刻图案的场景**（制作人 2026-11-24 提出；具体表现是默认做法）：选好要刻的图案后，右边的断臂转轮移到画面中间、放大，其余画面压暗；按住轮子上下拨动看整圈（松手停在拨到的位置），直接点要刻的那一格；Esc 或"不刻了"退出。刻上的那一格闪一下，手臂再移回右边。当铺买图案、赎回图案也用这个场景（赎回只能刻回原来那个轮子）。
- **只能刻在空格上**（制作人 2026-11-24 定）：有图案的格子不能覆盖；想刻在那一格，要先去当铺把它擦掉。轮子刻满了就刻不上这个轮子；三个轮子都满了，这一次只能不刻。
- 赖子不顶替空格；三个都是赖子手上不变；赖子不能拿在手上。来源：精英和诏令的三选一里 10% 有一个赖子；大转盘"新图案"10% 是赖子；每家当铺 10% 卖一件赖子（150 金）。印记怪不给赖子。

## 六、路线：两个出口和新手教程

### 6.1 两个出口（制作人定）
- 不在一个地方选洞口：**下一层有两个候选的层，地图上有两个出口，分在不同位置**，走哪个出口就去哪个候选。
- **出口的外观不一样**：按通向的那一层有多凶，分扬着尘、滴着水、起着雾三种；**鼠标停在出口上显示一句不说破的话**。
- **出口不标下一层的类型，也不告诉玩家下一层的怪掉多少血**（制作人定，去掉了楼梯口情报）。
- 不说破的话（制作人：更模糊一点）只按"下面有多凶"分三档，每档三种说法：
  - 凶："下面有什么东西在动。""下面传来一阵闷响。""风从下面往上吹，带着一股腥味。"
  - 静："下面很安静。""下面黑得看不见底。""下面滴答滴答地漏着水。"
  - 其他："下面有爪子挠石头的声音。""下面隐约有回声。""下面有点潮。"
- 两个候选（默认做法）：一个是要打的层（普通，第 5 层起 30% 是精英），另一个可能是普通、大转盘、当铺、骨坛或营火。整条路线由本局种子决定。

### 6.2 地图从哪来（默认做法，讨论项）
- 地图写在 `route.ts` / `levels.ts` 里，是 11×7、9×7 的小图原稿；`npm run expand` 把它们放大成 16×11（外面包墙、拉长走廊，打法和原稿完全一样，求解器逐张核对），并自动给要分岔的图加第二个出口：离第一个出口尽量远，前面至少要打一只怪或开一扇门，和第一个出口差不多难走到。
- **制作人定**：大地图先这样放着，不加内容；第二个出口先不手摆。
- 正式版的方向（原案）：设计师手工做几十个房间片段，程序拼成地图，每层生成后都由求解器检查能通关、难度在目标区间。

### 6.3 新手教程（制作人定：开局 5 层做成教学关卡）
- 第一次开始游戏进教程。5 张固定的教学地图，一层教一件事（地图和提示的措辞是默认做法）：
  1. **井口**：走路（按住方向键一直走）、打怪（指着怪看生命 / 攻 / 防，自己算掉多少血）、大赤晶让掉血变少、大青晶、血瓶、出口不用清怪。
  2. **骨门**：骨钥在井苔身后，用骨钥开骨门；一只"打不动"的锈甲虫守着一袋金币（现在打它每下都是 0，会被耗死），拿了门后的大赤晶才打得动，但不划算。
  3. **岔路**：两条路都到出口——上面过血门（扣 50）加一只先出手的回声蝠，下面打两只怪、路上有大赤晶。
  4. **鳞厅**：精英封住出口，先拿宝石和血瓶再打。
  5. **井底**：井底之眼守着出口，打不过。**走近它就进一段剧情，然后直接开打**（制作人 2026-11-24：不要弹"打了会死"，免得玩家误会要不要打），打的过程在战斗窗口里演完，矿工倒下。死后剧情："……你在井口醒来。右臂没了，断口处长出一个空空的转轮。"之后的每一局从第 1 层开始，带着断臂转轮。
- **教程结束后的两段剧情**（制作人 2026-11-24 提出，Codex 写的讨论稿已经接进游戏，文案待制作人看）：
  1. **袖子里的响声**（两页）：教程第 5 层被井底之眼打倒，在井口醒来时出现，替换原来的断臂说明——发现右臂没了、断口上长着三只铜轮，"井底下，谁给我装了台老虎机？"；第二页说明刻线、拉杆、锁和"中间凑齐同一把武器"，带碎片结算和"去碎片商店 / 再下井"两个按钮。
  2. **第一道印子**（一页）：正式局第一次打完架、可以刻图案时（印记怪或精英给的；大转盘、诏令给的不算），先于刻图案窗口出现，按钮"看看图案"。
  - 两段都跨局只出现一次（重走教程时只给结算）。
- **教程没走完就倒下**（第 1～4 层被怪打死）：教程不算走完，弹"你倒下了"，从教程第 1 层重新走，不给灵魂碎片（制作人定）。只有第 5 层被井底之眼打倒才是剧情里的那一下。
- 画面最下面有一条**教学提示条**，按玩家走到哪一步换下一句。求解器检查过：教程里怎么走都能走到第 4 层出口。
- **正式局不再有提示**（制作人定）：没有楼层提示，也没有底部的说明小字，查看目标时底部显示详情，移开后只显示刚发生的事。

## 八、画面、界面和操作

### 8.1 画面方向（制作人定：A · 斜俯视立体 + 机械臂转轮）
- **已确认**：高精度像素风。
- 斜俯视的立体像素：格子有厚度、墙有侧面和顶面，角色和怪物站在格子上、脚下有影子（参考《陷阵之志》的可读性）。
- 断臂转轮画成接在断口上的铜铁机械小臂：三个竖转轮嵌在小臂里，旁边一根红头拉杆，转轮下面是锁扣，再下面一个"用血转"按钮。
- 布局：左边 1～20 层进度条，中间大地图，右边机械臂，顶栏一排数值；怪物头上不挂掉血牌，目标详情（生命 / 攻 / 防 / 特性 / 掉落）固定显示在地图下方；打怪时画面中间弹战斗窗口。
- 深度配色（交接稿建议）：浅层潮湿青灰石、矿灯暖黄；中层盐晶白、锈铁橙；深层墨绿井水、暗紫岩层。可走格和数字的亮度保持稳定。
- 正式美术由 Codex 负责；现在的白盒是程序画的，接口不变，素材可以直接替换。

### 8.2 现在的白盒做了什么
- 逻辑画布 640×360，整数倍放大（1280×720 是 2 倍）；地图每格 26 逻辑像素。
- 转轮"爽"：拉杆下压 → 轮子带拖影滚动 → 一个个"咔"地停下 → 连成一线时画面大震、中奖线发金光、武器名大字跳出来；三个空格是一声闷响。
- 老电视（CRT）滤镜（扫描线、轻微弧面、四角暗），默认开，F2 或设置里开关。
- 矿灯光照（主角附近暖、远处冷暗，最暗保留 6 成亮度），墙缝滴水；数值变化时跳一下（变多绿、变少红）。
- 出口按通向的层冒扬尘、滴水或起雾。
- 音效是程序合成的占位声音（咔、拉杆、叮叮叮、闷响、打击、捡东西、滴水），正式音效另找。

### 8.3 开局界面、设置、暂停（默认做法，讨论项）
- 开局界面：背景是往下看的一口深井、一个矿工慢慢往下坠；菜单：继续游戏（有存档时）、开始游戏（有存档时叫"重新开始"，先问一次）、设置、退出游戏。
- 设置：老电视滤镜、全屏、音量（五档）、战斗动画（正常 / 快 / 跳过）、重新走新手教程。自动保存。
- 游戏中 Esc 暂停：继续、设置、回到开局界面、退出游戏。

### 8.4 操作
- 鼠标：指向格子，在地图下方看详情，点格子行动，点远处自动寻路，一格一格走过去。
- 键盘：方向键 / WASD 走一格；**按住方向键连续走**（制作人提出；默认做法：只穿过空地和道具，前面是怪、门、出口、设施时停下，要再按一次）。R 拉杆。
- 试玩快捷键：F9 重新走新手教程。

## 九、技术方案

- **已确认**：游戏框架 **LÖVE（Love2D）**，逻辑用 **Lua**。代码在 `crazykkkon/descent` 的 `love/` 目录（制作人倾向）。
- **TypeScript 原型**（`src/core/`）是规则的参照实现。改规则的流程：先改原型 → `npm test` → `npm run vectors` 导出标准算例 → 改 `love/src/core/` → `npm run love:test` 必须 0 条不一致。现在对账 11240 条，全部一致。
- **求解器和设计工具**继续用 TypeScript（制作人倾向）：
  - 求解器：状态是"已经处理掉哪些格子"，每个状态只留生命最高的路线；宝石、钥匙、金币袋能走到就捡，血瓶当成可选。可以指定走哪个出口。
  - `npm run mainline`：按种子生成整条路线，按"走哪个出口去哪层"连续求解（不算转轮和设施，是保守下限）。
  - `npm run expand`：小图放大成 16×11 并加第二个出口，结果在 `src/core/bigmaps.ts`（不要手改）。
  - `tools/fill.ts`：在画好的墙壁里试摆怪物和奖励。
  - 地图池由原型导出到 `love/src/data/pools.lua`（不要手改）。
- **LÖVE 自动测试**：`DESCENT_AUTOTEST=1 xvfb-run -a love .`——开局界面、设置、新手教程（第 5 层被打死、断臂剧情）、长按方向键、再用强角色走完 20 层（刻图案、转轮、两个出口、大转盘、当铺、骨坛、营火、诏令、井租、通关）。截图在 `~/.local/share/love/descent/`。
- **存档**：每走一步存到本地，继续时地图不变；死了清掉存档。跨局只存"教程打过没有"和设置。
- **试玩分发**：推送到 `main` 自动打 Windows / Mac 安装包（未签名，第一次打开要手动允许）：https://github.com/crazykkkon/descent/releases/tag/love-latest 。网页原型停在井的契约版，不再更新。
- **字体**：白盒用 Noto Sans SC（开源可商用）的常用字子集；正式版是否换像素中文字体是讨论项。

## 十三、和同类游戏的区分

| 对比点 | 经典魔塔类 | 《坠井者》 |
|---|---|---|
| 地图 | 固定关卡 | 每局换路线、换图，由求解器保证能过 |
| 钥匙和门 | 多种颜色的钥匙 | 只有一种骨钥，另有用生命换的血门 |
| 过关 | 按固定关卡推进 | 走到出口即可；哪些怪值得打要自己判断；只能往下 |
| 武器 | 捡到就用 | 刻在断臂转轮上，要自己转出来；刻得越多越容易转到 |
| 运气 | 没有 | 只在转轮、大转盘和"走哪个出口"上，赌不赌自己定 |
| 题材 | 塔、勇者、公主 | 古井、井底生态，全部原创怪物和设定 |

开发中只借鉴"固定数值战斗"这类通用机制，地图、怪物、美术、剧情、界面全部原创，不使用任何现有游戏的素材和名称。

## 十四、主要风险

| 风险 | 应对 |
|---|---|
| 新手看不懂数值玩法 | 开局 5 层教学关卡（第 1 层就教"你每下打掉 你的攻 − 它的防"）；战斗窗口把每一下演出来 |
| 转轮太难转到，玩家觉得被运气耍 | 一直显示几率；锁轴、刻多格都能提高几率；数值平衡时再看 |
| 太容易 / 太难 | 求解器按种子跑整条路线检查；平衡阶段统一调 |
| 大地图拉长后显得空 | 制作人定先这样；以后在 16×11 上重新摆内容 |
| 单局太长 | 记录每层耗时，超时的层改短 |
| 带着不够的状态下楼，下一层过不去 | 玩家自己的决定，出口不剧透；走进死局提示只能新开一局 |
