# 最后的绿洲

沙漠末日题材的环形生存城建小游戏（微信 / 抖音小游戏），使用 Cocos Creator 3.8 开发。

- 设计方案：[docs/game-design.md](docs/game-design.md)
- Cocos 工程与打开方式：[client/README.md](client/README.md)

## 当前进度：M1 玩法原型

- 心泉塔：4 档功率（关闭/低/标准/超载），覆盖范围、燃料消耗、抽水量、井水下降、超载损坏
- 5 圈环形地图（共 60 个地块），各圈温度实时计算，地图按温度着色
- 昼夜温差：白天酷热、夜晚寒冷，心泉塔白天降温、夜里供暖
- 6 种建筑：住所、冷凝器（夜班）、沙地农场、拾柴站、拆解站、医馆
- 资源：水、粮食、燃料、零件；人口：劳工、病人、孩童；民心：盼望、躁动
- 剧本事件：第 6 天沙暴、第 10–11 天热浪，提前 24 小时预警
- 激励视频广告：最后的希望（失败回档）、商队来援（预警时）、全员加班（立即完工）
- 12 天胜利条件、失败条件（全灭 / 盼望归零 / 躁动满）

## 开发工具（不需要 Cocos）

```bash
npm install
npm run preview     # 浏览器试玩：http://localhost:8080
npm test            # 核心逻辑单元测试
npm run sim         # 自动模拟 200 局，统计胜率（调数值用）
npm run typecheck   # 类型检查（含 Cocos 代码，用官方 cc 类型声明）
```
